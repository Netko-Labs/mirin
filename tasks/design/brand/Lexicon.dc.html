Voice — 02

Lexicon

The words mirin owns, the words it refuses, and the exact line the brewing metaphor is not allowed to cross.

The metaphor stops at the API
Brewing language lives in marketing copy, CLI flavour text, release posts and the mascot. It never touches a command name, a config key, a type, a file path or an error message. A build command must be greppable and boring — that is why it is mirin build and never mirin brew. Cute APIs cost people hours; cute marketing costs nothing.
Words we use
brewed / brewing — building, in flavour contexts only
main process — the Bun side. Not “backend”.
renderer — the web side. Not “frontend”, not “webview”.
native core — the Rust library. Not “the binding”.
typed RPC — always both words. It is the differentiator.
window — a real OS window. Never “screen” or “view”.
pre-alpha — the status, stated plainly, every time.
Words we never use
blazing fast — show a number or say nothing
simply / just — tells the stuck reader they are stupid
seamless / effortless — describes nothing
production-ready — not until it is. Then say the version.
Electron killer — loses the argument for us
Bun-compatible — Bun IS the runtime; never hedge it
leverage / empower — use “use”
Naming
mirinjs is the name of the library, in the wordmark and in prose. Lowercase everywhere, including at the start of a sentence.
The binary stays mirin — short to type, and already shipped. Write it as a command, never as the product name.
Scope is @mirinjs/*. The repo is currently mirin — README and docs still say “mirin” and need a pass.
Kome is capitalised — it is a name.
CLI verbs are plain and predictable: dev build release init check doctor skill.
Headings are sentence case. Never Title Case, never ALL CAPS outside the mono eyebrow label.
Kome in copy
Kome is the logo — neutral face, in every logo slot. It also appears in empty states, 404s, CLI status, release posts and stickers, where its expression changes.
Kome never: speaks in first person, gives instructions, or wears a non-neutral expression in a logo slot.
Kome is never anthropomorphised in prose — no “Kome says”, no mascot narration. It reacts; it does not talk.
The house sentences — reuse these verbatim
Desktop apps, brewed in Bun.
Your main process is Bun. Your UI is real Chromium. The native layer is Rust you never install.
One engine on every platform — identical rendering, identical devtools.
Pre-alpha, and the version number means it.
