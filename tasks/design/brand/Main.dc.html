What mirin is

Desktop apps, brewed in Bun.

mirinjs is a desktop application framework where the main process is Bun, the UI is real Chromium on every platform, and the native layer is Rust you never have to install. Not an Electron wrapper. Not a Node port.

Four principles — every decision answers to these
01
Say the status out loud
Pre-alpha means the badge says pre-alpha, on the hero, above the fold. A framework that oversells its maturity is one nobody trusts twice.
02
Show the window
A real capture of a real app beats any diagram, benchmark, or adjective. If a claim can be screenshotted, screenshot it instead of writing it.
03
Bun, without hedging
Never soften it into “Bun-compatible” or “also works with Node”. The runtime is the position. Hedging it throws away the only thing that makes mirin different.
04
Write to a peer
The reader has shipped software. Never explain what a main process is, never apologise for complexity, never pad with a 101 section they will skip.
