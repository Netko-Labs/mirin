Foundations — 03

Type

Three faces, each with one job and a hard boundary. The serif is the warmth; it earns that by never appearing where someone is trying to get work done.

Instrument Serif
display
Desktop apps, brewed in Bun.
Only: landing hero, marketing section openers, blog post titles, social cards. Never: docs bodies, docs headings, app UI, buttons, CLI. Regular weight only — never bold it.
Space Grotesk
interface & body
Everything a reader actually reads: docs, nav, buttons, labels, tables, the wordmark.
Weights 400 / 500 / 700 only. Headings tighten to -0.03em; body stays at 0.
JetBrains Mono
code & labels
bun create mirinjs my-app
await rpc.greet.query({ name })
Code, file paths, versions, CLI output, and the small uppercase eyebrow labels used across this book.
Scale
display / 64Hero headline
h1 / 36Page title
h2 / 24Section heading
body / 16Docs paragraph, 1.65 line-height, 66ch max
small / 13Captions, table cells, sidebar items
eyebrow / 11Section label
Do: one serif moment per page, at the top, then get out of the way. Measure caps at 66ch. Let headlines wrap with text-wrap: pretty.
Don't: serif in the docs, italic serif for emphasis inside prose, letter-spaced body text, or a fourth face because a page “needed something”.
All three are Google Fonts, which is the one font host the site's CSP allows. Ship fallback stacks with close metrics — PNG and PDF exports of these boards render the fallback, not the real face.
