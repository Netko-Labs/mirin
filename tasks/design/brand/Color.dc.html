Colour

One accent. Amber does every job an accent does — links, focus, primary action, active nav, the brew line. There is no second accent, and adding one is a change to this document, not a local decision.

There is no warning colour. Amber is the brand, so an amber warning is indistinguishable from a link — warnings use error at lower emphasis.
Proportion — 70 / 25 / 5
ink 70
rice 25
Amber is 5% of any surface. It marks the one thing that matters on a screen. An amber-heavy page reads as a warning, not a brand.
