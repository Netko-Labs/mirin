Create an app

Scaffold a new mirin project, install its dependencies, and get a native window rendering React with typed RPC in both directions.

bun bunx
bun create mirinjs my-app
cd my-app && bun install
bun run dev
The first run downloads the pinned CEF runtime once (several hundred MB) into ~/.mirinjs/cef/. No Rust toolchain is needed — the native core ships prebuilt.
What you get
A mirin-owned native window rendering React, a typed greet query round-tripping to the Bun process, and live tick events pushed back to the UI.
