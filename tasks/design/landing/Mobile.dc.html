Desktop apps, brewed in Bun.

The main process is Bun, not Node. Real Chromium on macOS, Windows and Linux. Typed RPC between them, and a CLI your coding agent can drive.

$ bun create mirinjs my-app
$ bun run dev

Typed RPC

Define it once. The UI already knows.

The renderer imports the router's type, never its code. No codegen, no channel strings.

main/rpc.ts
export const router = rpc.router({
  greet: rpc.query(async (n: string) => …),
})
type only
ui/api.ts
const api = client<Router>()
await api.greet('world')
Promise<string> — inferred
Agent tooling

Your agent can see the app run.

Most desktop frameworks are a black box to a coding agent. mirinjs closes that loop.

$ bunx mirin check
✓ window ready — 1 of 1
✓ screenshot — w1.png
✓ no renderer errors
