The window cat

Netko Labs is already a cat name. A cat sitting in a window frame ties the parent brand to the product in one shape — and cats sitting in windows is a real thing, not a stretch.

silhouette @ 16px
app icon lockup
error / 404 pose
Why it works: a mascot with a face carries expression — error pages, empty states, loading, release posts. The window frame with real traffic lights says "desktop" without a word of copy.
Tradeoff: cat mascots are everywhere in dev tooling, and it drops the mirin name connection entirely. Needs a distinctive shape to not read as generic.
