---
title: mirin skill
description: Install the agent skill into an existing project.
---

```bash
bunx mirin skill
```

Installs the Mirin agent skill into `.claude/skills/mirin`, so a coding agent
working in your repository knows the API, the CLI and the project layout without
inferring them from your source.

New projects get this from [`mirin init`](/docs/reference/cli/init) already.

## What it installs

- The API surface and the shapes it expects.
- The CLI commands, their flags and their exit codes.
- The verification loop: how to run `mirin check`, and where the event stream
  and screenshots land.
- The conventions a Mirin project follows.

## Keeping it current

The skill ships with the CLI, so it moves when Mirin moves. Re-run
`mirin skill` after upgrading — an agent working from a stale skill will
confidently write code against an API that no longer exists.

<Callout type="info">
Commit the installed skill. It is project configuration, and every contributor's
agent should be working from the same one.
</Callout>
